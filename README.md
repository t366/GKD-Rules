## 合并逻辑

使用 `merge_rules.py` 进行合并，核心逻辑：

1. **按优先级合并** — 高优先级源的规则优先保留，低优先级源补充
2. **同名规则组去重** — 相同 name 的 group 合并规则并去重
3. **规则指纹去重** — 基于 matches/anyMatches/excludeMatches 生成 MD5 指纹，去除完全重复的规则
4. **key 重编号** — 合并后对 group key 和 rule key 重新编号
5. **应用按名称排序** — 输出按应用名称排序

## 使用方式

在 GKD 应用中添加订阅链接，指向 `merged_subscription.json5` 文件的原始地址即可。
